# BJobers

A hackathon project repository containing the building blocks for a chatbot-style experience.

## Repository structure

- `Hackathon/backend/` — Python backend code, including `chatbot_backend.py`
- `Hackathon/data/` — source material used by the project
- `Hackathon/scripts/` — data-extraction and vector-database setup scripts
- `Hackathon/ui/` — HTML, CSS, animation, and image assets for the interface

## Getting started

1. Review the scripts and backend code to identify their dependencies and any required environment variables.
2. Create an isolated Python environment.
3. Install only the dependencies required by the code you plan to run.
4. Keep secrets out of commits; store local credentials in environment variables or a git-ignored `.env` file.

## Development notes

This repository is a useful starting point for documenting how data preparation, retrieval, backend logic, and a web interface fit together in a hackathon prototype. Future improvements could include a dependency manifest, setup instructions, tests, and an architecture diagram.
